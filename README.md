## 🛠️ Hướng Dẫn Nhanh (Quick Start Guide)

### 1. Quay Vùng Màn Hình Cần Thiết
- **Windows:** Bấm `Windows + Shift + S` để chụp vùng chọn, hoặc dùng ứng dụng **Snipping Tool** / **OBS Studio** để quay video ngắn.
- **macOS:** Bấm `Command + Shift + 5` > Chọn **Quay một phần màn hình**.

### 2. Chèn Vào Microsoft Word
1. **Dạng Ảnh Động (GIF):** 
   - Chọn `Insert` > `Pictures` > `This Device...` hoặc kéo thả trực tiếp file `.gif` vào Word.
2. **Dạng Khung Video (Thumbnail + Link):**
   - Chèn một bức ảnh đại diện đẹp vào Word.
   - Chuột phải vào ảnh > chọn `Link` > Trỏ đến đường dẫn file video trong máy.
